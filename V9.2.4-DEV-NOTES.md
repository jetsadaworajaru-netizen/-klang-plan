# Klang Plan V9.2.4 Supabase Persistence DEV

This build continues from V9.2.3 and keeps the existing V9.1.2 member/auth/lesson-plan flow intact.

## Added in V9.2.4
- Course Workspace now has a cloud-sync layer for `courses`.
- Local storage remains as an offline/fallback cache.
- On login, cloud and local course drafts are merged by `client_id` and `updated_at`.
- Course edits are cached locally immediately and then synced to Supabase when the V9.2.4 migration exists.
- Course deletion removes the matching cloud row first, then local cache.
- UI shows Cloud / Local / sync-error status and provides a manual sync button.
- Added additive migration `supabase-v9.2.4-persistence.sql` for course/workflow tables and owner-only RLS.

## Important
The migration has NOT been applied to the production Klang Plan Supabase project from this build. The current ChatGPT Supabase connector only exposes the separate `klang-research-staging` project, so production was intentionally left untouched.

## Next development step
After the Klang Plan Supabase project is available to the connector (or the migration is applied manually), verify cloud persistence with a member account. Then continue Course Workspace into lesson-plan generation linked by `course_id` / `unit_id` and resources/assessment outputs.
