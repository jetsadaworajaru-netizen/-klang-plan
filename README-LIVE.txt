KLANG PLAN V8.8 — COMPLETE LESSON PLAN

เพิ่มเติมตามการทบทวนระบบ:
1. ภาคเรียน + ปีการศึกษา
2. ตัวเลือก “เพิ่มวันที่สอน” เปิด/ปิดได้
3. ตัวเลือก “เพิ่มส่วนลงนาม/รับรองแผน” เปิด/ปิดได้
   - ครูผู้สอน
   - ผู้อำนวยการ
   - ตำแหน่ง
   - รูปแบบการรับรอง
4. Prompt แยกชัดเจน:
   A ข้อมูลหลักสูตร
   B ข้อมูลพื้นฐานของแผน
   C ข้อมูลผู้สอน
   D การรับรอง/ลงนาม
   E องค์ประกอบทางวิชาการ
   F แนวทางการออกแบบ
5. องค์ประกอบแผนหน้าเดียวครบขึ้น:
   - สาระสำคัญ
   - จุดประสงค์
   - สาระการเรียนรู้
   - สมรรถนะ
   - คุณลักษณะ
   - ขั้นกิจกรรม + เวลา
   - คำถามกระตุ้นคิด
   - สื่อ/แหล่งเรียนรู้
   - ชิ้นงาน/ภาระงาน
   - การวัดประเมินผล
   - ความแตกต่างระหว่างผู้เรียน
   - บันทึกหลังสอนแบบย่อ
6. สไตล์มี Preview จำลอง 8 แบบ + คำอธิบาย + ช่องแนวทางเพิ่มเติม + Quick style hints
7. คลังตัวชี้วัดกรอง ช่วงชั้น → ชั้น → กลุ่มสาระ → ค้นหา และเลือกตัวชี้วัดกลับไปสร้างแผนได้
8. ปุ่ม Prompt ต่อยอดชัดขึ้น:
   - ใบงาน
   - แบบทดสอบ
   - ใบความรู้
   - Rubric
   - เกม
   - Teaching Pack
